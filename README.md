An AI-powered data analytics tool that automates data cleaning, analysis, visualization, and insight generation for e-commerce datasets.

## Problem Statement
Manual data analysis is time-consuming and error-prone. Businesses need faster and automated insights for decision-making.

---

--Solution--
This project automates the entire data analysis pipeline:
- Data cleaning
- Exploratory Data Analysis (EDA)
- Visualization
- AI-based insight generation

---


⚙️ Features

✅ Automated data cleaning (missing values, duplicates)  
✅ Dynamic KPI dashboard  
✅ Interactive filters  
✅ AI-generated insights  
✅ Data visualization (charts & graphs)  
✅ Download cleaned dataset  

---

## 🧠 Tech Stack

- Python (Pandas, NumPy)
- Streamlit
- Plotly
- Scikit-learn (optional)

---

## 📊 Sample Insights

- Top-performing category identified automatically  
- Region-wise sales trends detected  
- Loss-making transactions highlighted
